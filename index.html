The problem

AI writes the code. Who understands it?

Coding agents ship features in minutes, and they bring in patterns, libraries and ideas the developer never chose. The code works, so nobody stops to learn it.

Then something breaks at 2 a.m., and nobody on the team can explain what the code does. We call that gap comprehension debt: concepts that landed in your codebase versus concepts someone actually understands.

How it works

Three steps. Two minutes to set up.

No tokens to copy, no environment variables. Install it, sign in in the browser, and keep coding.

Add the plugin from the MindStitch marketplace in Claude Code, run /mindstitch:login, and approve in your browser. That's it.

Refresh token rotation

A refresh token gets a user a new access token without logging in again. With rotation, each refresh token works exactly once: using it returns a fresh pair and invalidates the old one.

Why it's here

Your login now issues long-lived refresh tokens. Rotation means a leaked token is only useful until its owner refreshes, and reuse of an old one revokes the whole chain.

# auth/tokens.py
def rotate_refresh_token(old_token):
    family = revoke(old_token)  # reuse → revoke family
    return issue_pair(family=family)

FAQ

Questions

Does MindStitch slow down my agent?

No. The plugin collects changes locally and sends them once at the end of a turn, in well under a second. If MindStitch is unreachable, your session carries on and events are sent later.

Which tools does it work with?

At launch: Claude Code (plugin) and VS Code, Cursor, Windsurf and VSCodium (extension). Support for other coding agents with hooks is planned.

Can my manager read my code or my answers?

No. Managers see which concepts you've met and your check scores. They never see code snippets, and they only see a typed answer if it's flagged for review.

Can we run it on our own servers?

Yes, on the Enterprise plan. The self-hosted edition is the same software we run, packaged for Docker Compose or Kubernetes, and it can work fully offline with catalog-only cards.

When can I use it?
